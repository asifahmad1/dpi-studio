# DPI Studio

An offline, single-file browser tool that converts PNG/JPEG images to a selected print density (300–600 DPI), with optional print-width resizing, format-specific metadata writing, readback verification, and batch ZIP export.

## Use
Open `DPI-Studio-Offline.html` in any modern browser. No installation, no server, no internet connection needed — everything runs locally on your device.

## Files
- `DPI-Studio-Offline.html` — the complete application (HTML/CSS/JS in one file).
